# Precios de juguetes

Calcula el precio de venta (costo + %), redondea hacia arriba y exporta la lista a PDF.
Los datos se guardan en el navegador (localStorage).

## Correr local
```
npm install
npm run dev
```

## Subir a GitHub Pages
```
git init
git add .
git commit -m "Precios de juguetes"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/precios-juguetes.git
git push -u origin main
npm run deploy
```
Luego en GitHub: Settings > Pages > Branch `gh-pages` / root.
